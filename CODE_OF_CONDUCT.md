# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Read the full text there; it applies to all project spaces, including issues, pull requests and discussions.

In short: be respectful, assume good faith, give and accept feedback gracefully, and keep harassment out.

## Reporting

To report a violation, use GitHub's own tools: report the content or user through GitHub's reporting
feature, or open a private security advisory on this repository and mark it as a conduct report. Maintainers
will review it and respond with the enforcement steps described in the Covenant.
